Impersonation Check

Anyone can type your company's name into the From line. Whether the receiving server believes it depends on public records. This reads them.

Reads the public mail records of one domain through a public DNS resolver, and looks up fifteen similar names to see whether they are registered. It never visits them. The results are not stored. Sixty checks per hour.
